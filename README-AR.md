# SBM - Smart Business Maker

منصة ذكية لتحويل أفكارك إلى تطبيقات بمساعدة الذكاء الاصطناعي

## الميزات

✅ Chat مع AI متعدد  
✅ محرر أكواد احترافي  
✅ نشر فوري للتطبيقات  
✅ إدارة المشاريع  
✅ قاعدة بيانات قوية  
✅ واجهة عصرية  

## البدء السريع

### باستخدام Docker

```bash
git clone https://github.com/ecoffercom-dot/SBM.git
cd SBM
docker-compose up -d
```

افتح: http://localhost:5173

## التقنيات

- React 18
- Node.js + Express
- PostgreSQL
- Tailwind CSS
- Docker
